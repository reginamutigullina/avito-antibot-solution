# Определение автоматизированного трафика по суточным событиям

Основной файл решения — [`bot_solution.ipynb`](bot_solution.ipynb). Он строит
признаки из событий, сравнивает baseline с улучшенной моделью на временных
отрезках и создаёт `submission.csv`. В ноутбуке приведены пояснения к этапам
обработки, проверке и ограничениям подхода.

## Воспроизведение

Код проверен на Python **3.12.14**; точные версии библиотек указаны в
`requirements.txt`. Используется официальный файл метрики `metric.py`,
предоставленный вместе с заданием.

1. Скопировать `train.csv`, `test.csv` и `events.csv` либо `events.csv.gz` из
   набора задания в папку `data/` рядом с ноутбуком. Данные в этот репозиторий
   не включены.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Выполнить все ячейки `bot_solution.ipynb` по порядку. Последняя ячейка
   создаст `submission.csv` в корне проекта.

`random_state=42`; для экспорта score округляется до 10 десятичных знаков.
На использованном наборе данных SHA-256 полученного после запуска
`submission.csv` совпадает с отправленным файлом:

```text
9ef51bc0d12077680afff4793a2e3a5e384aba3c43b615d4adf16abf55555f40
```

Внешние API и предобученные языковые модели для вычисления признаков и score
не используются.

## Подход и результат

Сначала удаляются точные дубликаты событий. Для каждой куки используются
только события `window_start_ts <= event_ts < window_end_ts`. Агрегаты
описывают количество и состав действий, разнообразие объявлений, категории и
запросы, паузы, всплески и последовательности событий. `cookie_id` нужен лишь
для соединения таблиц и записи ответа.

Проверка проводится на более поздних датах train без перемешивания по времени.
Baseline — случайный лес с двумя признаками (`n_events`, `item_id_unique`).
Итоговая оценка — среднее `HistGradientBoostingClassifier` и
`ExtraTreesClassifier`, обученных на всех размеченных куках.

| Период проверки | Baseline, P@R≥0.7 | Итоговая модель, P@R≥0.7 |
| --- | ---: | ---: |
| 14–16 апреля | 0.1032 | 0.7326 |
| 17–19 апреля | 0.0931 | 0.8175 |

При отправке полученного по этому коду CSV платформа показала **0.77831** на скрытом test.
Это оценка по известным источникам трафика; её нельзя переносить без проверки
на новые типы автоматизированного поведения.
